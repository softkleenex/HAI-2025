# 대회 규칙 및 제약사항 (Constraints & Rules)

## 1. 데이터 관련 규칙 (Data Rules)
*   **공식 학습 데이터 부재:** 대회 측에서 제공하는 공식 학습 데이터가 없으며, **추론을 위한 평가 데이터(Test Set) 500장만 제공**됩니다.
*   **학습 데이터 구축:** 참가자는 모델 학습에 필요한 데이터를 **직접 수집 및 구축**해야 합니다. (External Data 허용)
*   **Test Set 활용 금지 (Data Leakage):**
    *   제공된 평가 데이터(Test Set)는 **오직 추론(Inference) 목적으로만** 사용해야 합니다.
    *   Test Set을 학습에 사용하거나, 파인튜닝(Fine-tuning)에 활용하는 것은 **데이터 유출(Leakage)**로 간주되어 엄격히 금지됩니다.
    *   Test Set의 분포를 보고 후처리(Post-processing) 룰을 만드는 행위도 지양해야 합니다.

## 2. 모델 구성 규칙 (Model Architecture Rules)
*   **단일 모델(Single Model) 제출 원칙:**
    *   최종 결과물은 **단일 모델**이어야 합니다.
    *   **허용:**
        *   **전처리용 검출기:** 얼굴 인식(Face Detection) 및 크롭(Crop) 등을 위한 별도의 검출기 모델을 앞단에 사용하는 것은 허용됩니다. (단, 검출기가 최종 Real/Fake 예측 값을 직접 산출하지 않아야 함)
        *   **순차적 파이프라인:** `[이미지 전처리/검출기] -> [분류 모델]` 형태의 직렬 구성은 허용됩니다.
        *   **단일 백본 & 멀티 헤드:** 하나의 백본(Backbone)을 공유하고, Head만 여러 개로 분기되는 구조는 허용됩니다.
    *   **불가 (앙상블 간주):**
        *   **병렬 결합:** 서로 다른 인코더(Encoder)나 백본을 병렬로 결합하여 사용하는 구조.
        *   **결과 앙상블:** 여러 모델의 예측 결과(Logits, Probability)를 평균(Averaging), 투표(Voting), 가중합(Weighted Sum) 등으로 결합하는 방식. (TTA 포함 여부는 추가 확인 필요하나, 통상적으로 단일 모델 내 TTA는 허용되는 경우가 많음. *단, Q&A 답변에서 모델 양상블과 다른 경우로 규칙 위반에 해당하지 않는다고 언급됨 - 재확인 필요*)

## 3. 시계열 및 동영상 처리 (Video & Time-series)
*   **입력 단위:** 동영상 데이터(mp4, mov 등)를 수집하더라도, 모델 입력은 **반드시 이미지 단위(Frame)**여야 합니다.
*   **시계열 학습 금지:**
    *   모델 내부에서 프레임 간의 순서나 시간적 관계(Temporal Information)를 학습하는 방식(RNN, LSTM, 3D CNN 등)은 **허용되지 않습니다.**
    *   각 프레임은 서로 독립적인 이미지로 처리되어야 합니다.
*   **후처리 허용:** 프레임별로 독립적으로 산출된 추론 결과를 **모델 외부에서** 종합(평균 등)하여 동영상 전체의 Label을 결정하는 후처리는 허용됩니다.

## 4. 코드 작성 및 제출
*   **재현성:** 심사 시 코드를 실행하여 동일한 결과가 재현되어야 합니다. (Random Seed 고정 필수)
*   **추론 코드:** 전처리 과정부터 추론까지의 전체 파이프라인이 포함되어야 하며, 시간/리소스 측정 시 전처리 시간도 포함됩니다.
