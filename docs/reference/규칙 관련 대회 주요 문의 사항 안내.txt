데이콘입니다.

대회 종료까지 약 2주 남은 시점으로, 규칙 관련 주요 문의사항을 아래와 같이 정리하여 안내드립니다.



1) Fake(딥페이크) 판정 기준 안내

본 대회에서 Fake는 한 사람의 얼굴에 다른 사람의 얼굴(정체성)을 씌운 경우(Identity Swap) 를 의미합니다.

즉, 얼굴 정체성이 변경되었는지 여부를 판별하는 문제입니다.



2) 업스케일/리사이즈/화질 개선 등 단순 변형 관련

본 대회는 정체성(identity)이 유지된 상태의 단순 보정·변형(예: 리사이즈, 업스케일, 화질 개선 등)을 판별하는 목적이 아닙니다.

평가 데이터 또한 정체성 변경(Identity Swap) 여부를 중심으로 구성되어 있습니다.



3) 외부 데이터 사용 관련 (법적 제약 및 검증 제출)

외부 데이터 사용은 가능합니다.

다만 참가자는 해당 데이터가 저작권·라이선스·개인정보 측면에서 합법적으로 학습에 사용 가능함을 확인하고, 외부 데이터 사용 시 출처·사용 근거를 명시해야 합니다.

또한 필요 시 운영진 검증을 위해 비공개 데이터 제출이 가능한 데이터셋에 한해 사용이 허용됩니다.



4) CC BY-NC / 재배포 금지 데이터셋 사용 가능 여부

비상업적 이용이 허용되고 합법적으로 접근 가능한 경우 사용 가능합니다.

단, 외부 데이터를 활용한 경우에는 운영진 검증 목적의 비공개 제출이 가능해야 하며, 이는 재배포에 해당하지 않습니다.



5) CLIP 등 멀티 인코더 구조 모델의 단일 모델 인정 여부

CLIP과 같이 하나의 단일 모델로 제공되는 아키텍처를 그대로 사용하는 경우,

텍스트 인코더와 이미지 인코더가 포함되어 있더라도 단일 모델로 인정되어 사용 가능합니다.

단, 해당 모델 외의 다른 모델/백본의 출력·임베딩을 추가 결합하는 방식은 허용되지 않습니다.



6) Exif/메타데이터 활용 관련

본 대회에서는 이미지 픽셀 정보만을 입력으로 인정합니다.

따라서 이미지 파일에 포함된 Exif 등 부가 메타데이터는 예측에 활용할 수 없습니다.

또한 혼선 방지를 위해, 전처리 단계에서도 활용하지 않는 것을 권장드립니다.



위 안내는 참가자 여러분의 원활한 참여를 돕기 위한 기준 정리이며,

세부 사항은 반드시 대회 규칙을 함께 참고해주시기 바랍니다.

감사합니다.
